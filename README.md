# EEEIC26---Short-Term-Load-Forecasting-for-Academic-Campi-based-on-DL-and-Feature-Engineering
Complete results of the experiments, with ablation studies on exogenous variables, for short-term load forecasting of an academic campus. Respective of the conference paper "Short-Term Load Forecasting for Academic Campi based on DL and Feature Engineering" submitted to 26th International Conference on Environment and Electrical Engineering by the authors Manuel X. M. Lopes, Carlos Grilo, João Sousa, Pedro Marques and Luís M.N. Távora. All models were developed using the NeuralForecast Library [1].

This repository contains .pdf files with the results for 24-hour-ahead load profile forecasting, [EEEIC26_24h_Full.pdf](https://github.com/manuel-lopes03/EEEIC26---Short-Term-Load-Forecasting-for-Academic-Campi-based-on-DL-and-Feature-Engineering/blob/main/EEEIC26_24h_Full.pdf), and day-ahead forecasting of total daily load (based on aggregation of 24-hour-ahead profile forecasts and day-ahead forecasts based on daily load data), [EEEIC26_1D_Full.pdf](https://github.com/manuel-lopes03/EEEIC26---Short-Term-Load-Forecasting-for-Academic-Campi-based-on-DL-and-Feature-Engineering/blob/main/EEEIC26_1D_Full.pdf).
